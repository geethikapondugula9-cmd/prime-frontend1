================================================================================
  [2] VOICE TRANSLATION FLOW (Main Feature)
================================================================================

  USER A (Browser)                  BACKEND                 GOOGLE CLOUD
  ================                  =======                 ============

  [1] User speaks
       |
       v
  [2] ScriptProcessorNode
      8192 audio samples
      Float32 PCM -> Int16 PCM
      Encode to base64
       |
       | WebSocket every 200ms
       | { event:"audio", audio:"<base64>" }
       v
                             [3] server.js receives
                                  |
                                  | Decode base64 -> Buffer
                                  v
                             [4] Write to gRPC stream
                                  |
                                  +------------------------------> Google STT
                                                                       |
                                                          INTERIM result (live)
                                                                       |
                                  <-----------------------------+  FINAL result
                                  |
                             [5] VoiceProcessor
                                 Accumulate finals
                                 into sentence buffer
                                  |
                             [6] Silence timeout fires
                                 English/Euro : 1500ms
                                 Indian langs : 1000ms
                                  |
                                  +------------------------------> Google Translate
                                                                       |
                                                              Translated text
                                  <-----------------------------+
                                  |
                                  | Send to BOTH users:
                                  | { event:"translation",
                                  |   originalText, translatedText }
                                  |
                                  +------------------------------> Google TTS
                                                                  (Neural2 voice)
                                                                       |
                                                                  WAV audio
                                  <-----------------------------+
                                  |
                                  | WebSocket to PARTNER:
                                  | { event:"audio_playback",
                                  |   audio:"<base64 WAV>" }
                                  v
  USER B (Browser)
  Decode base64 WAV -> Blob URL
  HTML5 Audio.play()
       |
       v
  [7] User B HEARS the translation
      in their own language!

================================================================================
  [10] GOOGLE CLOUD AI PIPELINE DETAIL
================================================================================

  SPEECH-TO-TEXT (STT)
  --------------------
  Package : @google-cloud/speech
  Method  : streamingRecognize (gRPC streaming)
  Config  :
    encoding       = LINEAR16
    sampleRateHertz= 48000
    model          = latest_long (enhanced)
    interimResults = true
  Feature : Auto-restarts every 50s (Google 60s stream limit)
  Output  : Interim (live preview) + Final (complete phrase)

  TRANSLATE
  ---------
  Package : @google-cloud/translate v2
  Method  : translate(text, { from, to })
  Input   : Finalized sentence + source lang + target lang
  Output  : Translated text string

  TEXT-TO-SPEECH (TTS)
  --------------------
  Package : @google-cloud/text-to-speech
  Method  : synthesizeSpeech()
  Config  :
    audioEncoding  = LINEAR16
    sampleRateHertz= 48000
    speakingRate   = 1.1 (slightly faster)
    voice          = Neural2 (highest quality)
  Output  : PCM bytes -> WAV header (44 bytes) added -> base64 -> WebSocket


================================================================================
  [11] PERFORMANCE OPTIMIZATIONS
================================================================================

  1. SINGLETON GOOGLE CLIENTS
     One shared STT, Translate, TTS client for ALL connections
     Saves 200-500ms per user (no re-authentication overhead)

  2. PRE-WARMING
     On WebSocket connect:
       + 500ms -> STT stream opened in background
       + 600ms -> Translate + TTS called with dummy text
     Eliminates cold-start delay on first actual speech

  3. ADAPTIVE SILENCE TIMEOUT
     English / European = 1500ms silence -> finalize + translate
     Indian Languages   = 1000ms silence -> finalize + translate
     Indian lang codes: te hi ta bn gu kn ml mr pa ur

  4. STT STREAM AUTO-RESTART
     Google STT max stream = 60s
     Server detects age > 50s -> gracefully restarts stream
     Accumulated sentence buffer preserved across restart

  5. AUDIO PLAYBACK QUEUE
     TTS audio stored in array queue (audioQueueRef[])
     Plays one WAV at a time sequentially
     Prevents audio overlap or interruption

  6. HARDWARE MUTE
     track.enabled = false -> mic off at hardware level
     Accumulated audio chunks cleared on mute
     Zero data sent to server when muted
