PRIMETALKER - PROJECT ARCHITECTURE AND FLOW
===========================================
Real-time Voice Translation Application

TECH STACK
==========

FRONTEND (React App - p1/)
  Framework  : React 18 + Vite + TypeScript
  Routing    : React Router v6
  State Mgmt : TanStack React Query + useState/useRef hooks
  UI Library : shadcn/ui (Radix UI primitives)
  Styling    : Tailwind CSS v3
  Forms      : React Hook Form + Zod
  Video SDK  : Twilio Video JS SDK v2
  Icons      : Lucide React
  Auth       : Supabase JS Client
  Deploy     : Vercel

BACKEND (Node.js - twil/)
  Runtime    : Node.js
  Framework  : Express.js
  WebSocket  : ws library
  AI STT     : Google Cloud Speech-to-Text
  AI Translate: Google Cloud Translate
  AI TTS     : Google Cloud Text-to-Speech
  Video Token: Twilio Access Token (JWT)
  Deploy     : Render or AWS EC2

EXTERNAL SERVICES
  Supabase   : Auth + PostgreSQL database
  Twilio     : Video calling (WebRTC SFU)
  Google Cloud: Speech + Translate + TTS APIs

USER JOURNEY - CREATOR
======================
1. Open /landing -> click Get Started
2. /auth -> login with Supabase
3. /rooms -> click Create Room
4. POST /create-room -> server returns roomId
5. /meeting/:roomId opens
6. WebSocket connects to ws://backend/audio-stream
7. POST /api/video-token -> get Twilio JWT
8. Share invite link with partner
9. LIVE CALL begins

USER JOURNEY - GUEST
====================
1. Receive link /join/:roomId
2. Enter name + select language
3. POST /join-room -> server registers participant
4. /meeting/:roomId opens
5. WebSocket + Twilio Video connect
6. LIVE CALL begins

VOICE TRANSLATION PIPELINE
===========================

Step 1: User speaks into microphone
Step 2: Browser captures audio (ScriptProcessorNode - 8192 samples)
Step 3: Convert Float32 PCM -> Int16 PCM -> base64
Step 4: Send via WebSocket every 200ms
          { event:"audio", audio:"<base64>" }
Step 5: Backend decodes base64 -> Buffer
Step 6: Write raw PCM to Google STT gRPC stream
Step 7: Google STT returns:
          INTERIM -> sent to browser as live preview
          FINAL   -> accumulated in sentence buffer
Step 8: After silence (1.5s or 1.0s for Indian langs) -> finalize sentence
Step 9: Google Translate converts to partner language
Step 10: Both users notified:
          { event:"translation", originalText, translatedText }
Step 11: Google TTS generates Neural2 voice audio (WAV)
Step 12: WAV sent to PARTNER:
          { event:"audio_playback", audio:"<base64 WAV>" }
Step 13: Partner browser decodes + plays audio
Step 14: Partner hears the translation in their own language!

REST API ENDPOINTS
==================

GET  /health               -> server status + active rooms
POST /create-room          -> create room, returns roomId
POST /join-room            -> guest joins, gets creator info
GET  /room-info?roomId=X   -> get room details
POST /leave-room           -> leave/delete room
POST /api/video-token      -> generate Twilio JWT

WebSocket: ws://server/audio-stream

CLIENT -> SERVER events:
  { event:"connected",  roomId, userType, myLanguage, myName }
  { event:"audio",      audio:"<base64>" }   (every 200ms)
  { event:"disconnect" }

SERVER -> CLIENT events:
  { event:"user_joined",        name, language }
  { event:"user_left" }
  { event:"transcript_interim", text }
  { event:"translation",        originalText, translatedText }
  { event:"audio_playback",     audio:"<base64 WAV>" }

GOOGLE CLOUD SERVICES DETAIL
==============================

1. SPEECH-TO-TEXT
   Package : @google-cloud/speech
   Method  : streamingRecognize (gRPC streaming)
   Config  : LINEAR16, 48000Hz, enhanced model, interim results
   Feature : Auto-restarts every 50s (Google 60s stream limit)
   Output  : Interim (live preview) + Final (complete phrase)

2. TRANSLATE
   Package : @google-cloud/translate v2
   Method  : translate(text, { from, to })
   Output  : Translated string

3. TEXT-TO-SPEECH
   Package : @google-cloud/text-to-speech
   Config  : Neural2 voices, 48000Hz, speed 1.1x
   Output  : PCM bytes -> WAV header -> base64 -> sent to browser

PERFORMANCE OPTIMIZATIONS
==========================

1. Singleton Google Clients
   One instance shared across ALL connections
   Saves 200-500ms per user (no re-authentication)

2. Pre-Warming (on WebSocket connect)
   STT stream warmed at 500ms delay
   Translate + TTS warmed at 600ms delay
   Eliminates cold-start on first speech

3. Adaptive Silence Timeout
   English/European  : 1500ms silence -> translate
   Indian Languages  : 1000ms silence -> translate (faster)
   Indian lang codes : te hi ta bn gu kn ml mr pa ur

4. STT Stream Auto-Restart
   Google max = 60s. Server restarts at 50s
   Accumulated sentence preserved across restart

5. Audio Playback Queue
   TTS audio queued in browser
   Plays one at a time (no overlap)

6. Hardware Mute
   track.enabled = false -> hardware-level mic off
